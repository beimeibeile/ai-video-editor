# 导演引擎系统状态总结

> 更新时间：2026-10-03
> 版本：v1.0（基础框架完成）

## 一、系统架构

```
自然语言剧本
    ↓
P23 剧本结构化解析器 (script_parser.py)
    ↓ 标准分镜JSON
P24 指令翻译器 (instruction_translator.py)
    ↓ 指令序列JSON
P25 中央调度器 (central_orchestrator.py)
    ↓ 任务DAG + 拓扑排序
执行器层 (jianying_executor.py / TTS / ComfyUI / Blender)
    ↓
最终剪映工程
```

## 二、已完成模块

### P23 剧本结构化解析器 ✅
- **角色识别**：已知角色匹配 + 正则识别（2-3字，后跟说/道/被/把等）
- **动作识别**：12种动作关键词（比耶/被打/攻击/掉下/爬上/摸头等）
- **情绪识别**：8种情绪（开心/愤怒/惊恐/委屈/得意/平静/惊讶/害羞）
- **场景识别**：8种场景（头像框内/抖音主页/商品橱窗/室外/室内等）
- **动作归属**：施动者/受动者区分（被动/主动/无标记三种结构）
- **复杂句子处理**：找"被"字前面最近的角色作为受动者
- **角色识别过滤**：黑名单 + 介词开头过滤 + 后缀过滤

### P24 指令翻译器 ✅
- **情绪→TTS参数**：8种情绪映射（pitch/speed/energy/voice_style）
- **动作→关键帧**：7种动作映射（position/scale/rotation/alpha）
- **场景→环境音**：8种场景映射
- **转场→特效参数**：6种转场映射
- **文字样式→排版参数**：4种样式映射
- **关键帧排序**：按(轨道, 时间)排序输出

### P25 中央调度器 ✅
- **任务DAG构建**：素材准备→各工具→最终合成
- **拓扑排序执行**：依赖关系自动解析
- **失败重试**：最多2次重试
- **死锁检测**：循环依赖检测
- **执行报告**：成功/失败/跳过统计

### 剪映执行器 ✅
- **工程创建**：1080x1920竖屏
- **素材准备**：背景占位 + 角色占位（纯色圆+角色名）
- **关键帧应用**：position/scale/rotation/alpha
- **文字添加**：每条文字独立轨道（避免重叠）
- **工程保存**：C盘默认目录

### 导演引擎统一入口 ✅
- **generate()方法**：一键串联P23→P24→P25
- **输出文件**：分镜JSON + 指令序列JSON + 执行报告JSON

## 四、已知限制

### 执行器层（占位实现）
- ⏳ TTS执行器：占位，待接入实际TTS API
- ⏳ 音频执行器：占位，待接入实际音频生成
- ⏳ 特效执行器：占位，待接入剪映特效API
- ⏳ 文字排版执行器：占位，待接入text_layout.py
- ⏳ ComfyUI执行器：占位，待接入视频生成
- ⏳ Blender执行器：占位，待接入3D动画生成
- ⏳ 最终合成执行器：占位，待接入ffmpeg合成

### P23解析器限制
- 基于关键词词典，无法理解复杂语义
- 代词指代（他/她/它）暂不解析
- 多义动作词可能误判
- 台词需要引号括起来才能识别

### P24翻译器限制
- 动作→关键帧映射较简单，缺乏细腻变化
- 角色位置初始化未根据场景调整
- 蒙版/转场/特效参数待完善

### 剪映执行器限制
- 角色素材为占位（纯色圆），非实际角色形象
- 蒙版/转场/特效未接入
- 音轨未实际生成

## 五、后续优化计划

### 优先级P0（核心能力）
1. **蒙版执行器**：接入mask_keyframe.py，支持圆形/矩形蒙版
2. **特效执行器**：接入剪映特效API（闪白/叠化/缩放等）
3. **文字排版执行器**：接入text_layout.py，支持竖排/错落/背景块等
4. **角色素材生成**：用ComfyUI生成实际角色形象，替代占位

### 优先级P1（重要能力）
5. **TTS执行器**：接入豆包TTS，支持多角色情绪配音
6. **音频混合**：环境音+音效+BGM+人声多层混音
7. **角色位置初始化**：根据场景自动设置角色初始位置
8. **P23深度语义增强**：引入LLM做更深度的剧本理解

### 优先级P2（增强能力）
9. **ComfyUI视频生成**：接入混元I2V/LTX等视频生成
10. **Blender 3D动画**：接入3D角色动画生成
11. **最终合成**：ffmpeg自动导出MP4
12. **质检闭环**：自动检测输出质量，反馈优化

## 六、关键技术沉淀

### 剪映坐标系统（已验证固化）
- 素材位置x: -1=左, 1=右；y: +1=上, -1=下
- 蒙版位置与素材位置一致
- 蒙版size=相对画布高度比例，全屏=1.0
- **剪映读取draft_content.json，修改蒙版必须同时改draft_info.json和draft_content.json**
- 文字片段同轨道时间重叠会报错，必须用独立轨道

### 导演引擎设计原则
- 标准分镜JSON作为P23→P24的中间格式
- 指令序列JSON作为P24→P25的中间格式
- 执行器可插拔，支持多种工具（剪映/ComfyUI/Blender）
- 任务DAG自动管理依赖关系
