# 剪映5.9 坐标系统验证结果（已验证，勿改）

## 素材位置坐标
- x: -1=左, 1=右, 0=中心
- y: **+1=上, -1=下**, 0=中心（y正=上）
- 单位：半个画布宽/高为1.0

## 蒙版位置坐标（2026-10-03验证通过）
- x: -1=左, 1=右, 0=中心
- y: **+1=上, -1=下**, 0=中心（y正=上，与素材位置一致）
- 验证工程：`蒙版坐标验证`（5个彩色圆形测试）

## 蒙版size参数
- **size = 相对画布高度的比例**，不是相对素材大小
- 全屏 = 1.0（=1920px）
- 头像框直径390px → size = 390/1920 = **0.203**

## add_mask方法注意事项
- center_x/y传入的是**像素值**，内部会除以素材半宽转为比例
- 直接传比例值会被除以540/960，变成接近0（错误）
- **正确做法**：构建后直接修改draft_info.json中materials.masks[].config
- width会自动计算为 size*1920/1080 = 0.356（相对宽度），实际像素=384px
- 圆形蒙版实际宽高相等，只是存储比例不同

## 头像框精确坐标（原视频720x1280 → 1080x1920）
- 原视频圆心：(165, 310)px，直径260px
- 放大×1.5后：(247.5, 465)px，直径390px
- 剪映蒙版坐标：**centerX=-0.542, centerY=0.516**
- 蒙版size：**0.203**（390/1920）
- feather：0.001（精确裁切）
