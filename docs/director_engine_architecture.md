# ai-video-editor 系统核心架构：导演引擎（Director Engine）

## 架构定位

导演引擎是系统的**核心大脑**，位于人类创意和工具能力之间，负责：
1. 读懂人类语言（剧本/创意）
2. 翻译成机器语言（工具指令/提示词）
3. 指挥调度各工具协同执行

```
┌─────────────────────────────────────────┐
│  输入层：人类自然语言（剧本/创意描述）      │
└──────────────────┬──────────────────────┘
                   ↓
┌─────────────────────────────────────────┐
│  导演引擎（核心）                          │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│  │ 剧本解析器 │ │ 指令翻译器 │ │ 中央调度器 │ │
│  │ P23      │ │ P24      │ │ P25      │ │
│  └──────────┘ └──────────┘ └──────────┘ │
└──────────────────┬──────────────────────┘
                   ↓
┌─────────────────────────────────────────┐
│  工具能力层（手）                          │
│  剪映工程 / TTS配音 / ComfyUI / Blender  │
│  文字排版 / 多音轨合成 / 特效库 / 蒙版     │
└─────────────────────────────────────────┘
```

## 三大核心模块

### P23：剧本结构化解析器（Script Parser）
- 输入：自然语言剧本/创意描述
- 输出：标准分镜JSON（scene_schema.json）
- 能力：
  - 角色识别（名称、形象、情绪、关系）
  - 动作解析（谁在什么时间做什么）
  - 情绪标注（每个角色每个时刻的情绪状态）
  - 音效点识别（动作音效、环境音、转场音效）
  - 节奏分析（每个镜头时长、转场类型）
  - 场景识别（地点、时间、氛围）

### P24：指令翻译器（Instruction Translator）
- 输入：结构化分镜JSON
- 输出：各工具的精准指令序列
- 能力：
  - 情绪→参数映射（委屈→TTS音色+表情提示词+身体语言）
  - 动作→关键帧映射（被打→闪白+位移+音效+震动）
  - 场景→环境音映射（寺庙→颂钵+佛寺气氛+空灵音色）
  - 节奏→剪辑映射（快切/长镜头/叠化）
  - 文字→排版映射（竖排地名/诗意字幕/标题logo）

### P25：中央调度器（Central Orchestrator）
- 输入：指令序列
- 输出：按依赖执行，自动处理工具间数据传递
- 能力：
  - 任务依赖图（先生成角色图→再做动画→最后合成）
  - 执行队列（并行/串行调度）
  - 失败重试（工具失败自动降级或重试）
  - 音画同步（对白对齐口型，音效对齐动作）
  - 资源管理（显存清理、临时文件管理）

## 设计原则

1. **理解优先**：先深度理解剧本，再动手做，不盲目生成
2. **精准翻译**：每个情绪/动作都有明确的参数映射，不靠猜
3. **可验证**：每一步输出都有结构化数据，可检查可修正
4. **可扩展**：新工具能力只需注册到翻译器的映射表，引擎自动调用
5. **失败可恢复**：调度器处理工具失败，自动降级或重试
