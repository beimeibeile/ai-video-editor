# 模式 B：仿制模板 — 完整流程

> **核心目标**：仿制原视频效果，生成可发布到剪映平台的模板草稿。其他用户打开模板后，用简单原始素材（无特效的图片/视频）替换标记为"可替换"的轨道素材，即可得到模板中的视频效果。
>
> **铁律**：素材只放原始件（图片/视频/音频/贴纸），所有特效/转场/滤镜/关键帧/蒙版/运镜全部在剪映工程内通过GUI实现。禁止在素材准备阶段给图片/视频加特效。

## 剪映模板机制（必须理解）

### 模板是什么
- 在剪映里制作完整视频（包含所有特效、转场、文字、音乐、多轨道叠加）
- 导出时选择"发布模板"
- 在"片段设置"中勾选哪些素材可以被其他用户替换
- 其他用户打开模板后，按顺序选择图片/视频替换可替换素材
- 特效、转场、滤镜、关键帧、蒙版、文字、音乐全部保留，替换素材后自动继承

### 可替换 vs 固定
| 类型 | 可替换？ | 说明 |
|---|---|---|
| 主轨道图片/视频 | ✅ 可替换 | 用户替换为自己的素材 |
| 画中画图片/视频 | ✅ 可替换 | 用户替换为自己的素材 |
| 文字 | ❌ 固定（或可编辑文字内容） | 字体/样式/动画保留 |
| 贴纸 | ❌ 固定 | 模板自带贴纸 |
| 特效/滤镜 | ❌ 固定 | 模板效果核心 |
| 转场 | ❌ 固定 | 模板节奏核心 |
| 关键帧/蒙版 | ❌ 固定 | 模板运镜核心 |
| BGM/音效 | ❌ 固定（或可替换音乐） | 模板氛围核心 |

### 多轨道叠加（模板还原的关键）
剪映专业版支持无限轨道叠加，同一时间段可同时存在：
```
上层：特效轨道 → 文字轨道 → 贴纸轨道 → 画中画轨道2 → 画中画轨道1 → 主轨道
下层：音频轨道（BGM/旁白/音效可多轨叠加）
```
- 电脑端无"画中画"按钮，将素材拖到主轨道上方的轨道即完成叠加
- 混合模式（滤色/正片叠底/变暗等）可创造特殊视觉效果
- 特效必须在最上层轨道
- 层级顺序决定遮挡关系

## 阶段 0：发起任务，上传参考视频

- 用户上传 1 个参考视频（mp4/mov 等）
- 记录本地绝对路径
- 抖音等在线视频：自动下载不可行时，请用户手动下载后上传
- **输出**：参考视频路径 + 基础信息

## 阶段 1：原视频深度分析

详细分析方法见 `video-analysis.md`，分析脚本见 `scripts/analyze_video.py`。

### 1.1 基础信息探测
```bash
ffprobe -v error -show_format -show_streams input.mp4
```
获取：时长、分辨率、帧率、码率、音轨数量/格式。

### 1.2 镜头分割（场景检测）
```bash
ffmpeg -i input.mp4 -filter:v "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep "showinfo"
```
- 阈值 0.3 默认；快剪视频用 0.4+，慢节奏用 0.2
- 输出：镜头列表（编号/起始/结束/时长）

### 1.3 每镜头抽帧分析
每个镜头中间位置抽 1 帧，Read 后分析：
- 景别（特写/近景/中景/全景/远景）
- 主体（人物/产品/文字/场景）
- 构图（居中/三分/对称/引导线）
- 色调（暖黄/冷蓝/青灰/高饱和）
- 运动方向

### 1.4 多轨道叠加关系分析（模板还原的核心）
通过抽帧和画面分析判断：
- **主轨道**：背景/基础画面是什么
- **画中画层数**：有几层叠加画面，各自的位置/大小/透明度
- **文字层**：字幕/标题/花字的位置/样式/动画
- **特效层**：粒子/光效/抖动/模糊等画面特效
- **贴纸层**：透明PNG/动图贴纸
- **混合模式**：滤色（去黑底）/正片叠底（去白底）/变暗等

### 1.5 运镜与关键帧分析
- 固定/推近/拉远/左摇/右摇/上移/下移/旋转/升格
- 关键帧参数估算：缩放起止值（如1.0→1.15）、位移方向、旋转角度、透明度变化
- 快切镜头（<0.5秒）标注为"硬切快剪"，不加关键帧

### 1.6 蒙版与抠像分析
- 蒙版形状：矩形/圆形/线性/镜面/自定义
- 蒙版参数：位置/大小/旋转/羽化
- 抠像类型：自定义抠像/色度抠图/智能抠像
- 蒙版动画：是否有关键帧控制蒙版移动

### 1.7 特效与滤镜分析
- 画面特效：粒子/星光/光效/抖动/模糊/故障等
- 全片滤镜：统一色调（青灰/暖黄/赛博/复古/清新）
- 局部特效：仅某些时间段的特效
- 特效素材：是否使用了透明通道特效素材（混合模式滤色）

### 1.8 转场分析
- 硬切/叠化/闪白/闪黑/缩放转场/滑动转场/旋转转场
- 转场时长（通常0.2-0.8秒）

### 1.9 字幕提取与识别
- 内嵌字幕流直接提取
- 否则抽帧OCR识别字幕内容、时间点、位置、字体大小、颜色
- 文字动画：打字机/弹入/淡入/模糊入场等

### 1.10 音频分析
- BGM：风格/BPM/是否有人声
- 旁白：起止时间
- 音效点：转场音/重鼓/定格音/氛围音的时间点

### 1.11 分析汇总
输出完整**仿制分镜表**（含轨道层级）：

| 镜头# | 时间 | 时长 | 主轨道 | 画中画1 | 画中画2 | 文字 | 特效 | 转场 | 可替换 |
|---|---|---|---|---|---|---|---|---|---|
| 1 | 0-2s | 2s | 图片1(背景) | 图片2(手机框) | — | "钩子" | 金色粒子 | 淡入 | 图片1,图片2 |
| 2 | 2-2.5s | 0.5s | 图片3 | — | — | 无 | 无 | 硬切 | 图片3 |

**可替换素材清单**：列出所有标记为可替换的素材位置和类型。
**特效实现清单**：列出所有需要在剪映GUI中实现的特效/转场/关键帧/蒙版。

## 阶段 2：仿制方案确认

- 输出完整分镜表（含多轨道层级）+ 可替换素材清单 + 特效实现清单
- 明确标注：哪些素材可替换、哪些固定
- 明确标注：哪些特效可通过GUI自动实现、哪些需手动微调
- **确认门控**：用户确认后进入素材准备

## 阶段 3：原始素材准备（只放原始件，不加特效）

### 3.1 比例适配（强制）
```bash
# 检测分辨率
ffprobe -v error -select_streams v:0 -show_entries stream=width,height -of csv=p=0 input.jpg

# 裁剪缩放至画布分辨率（9:16 → 1080×1920）
ffmpeg -i input.jpg -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920" output.jpg
```
裁剪后必须 Read 验证构图。

### 3.2 视频预处理（强制）
所有占位视频预处理为画布分辨率+H264+yuv420p+30fps+无音频：
```bash
ffmpeg -i input.mp4 \
  -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920" \
  -an -r 30 -c:v libx264 -pix_fmt yuv420p output.mp4
```

### 3.3 准备的素材类型（仅限原始素材）
| 素材类型 | 用途 | 说明 |
|---|---|---|
| 占位图片 | 标记可替换的图片位置 | 纯色/数字/简单图形，如"替换图片1" |
| 占位视频 | 标记可替换的视频位置 | 从原视频裁剪的镜头片段 |
| BGM | 背景音乐 | 从原视频提取mp3，或云端搜索 |
| 旁白 | 人声解说 | TTS生成或原视频提取 |
| 音效 | 转场/重鼓/定格 | 云端音效或原视频提取 |
| 贴纸 | 透明PNG/动图 | 模板固定元素 |
| 文字 | 字幕/标题 | 在剪映里添加文字层 |

### 3.4 禁止事项
- ❌ 禁止在素材准备阶段给图片/视频加特效、滤镜、转场
- ❌ 禁止用image_to_video生成带特效的动态片段（模板特效应在剪映里实现）
- ❌ 禁止提前合成整条音频（多音轨在剪映里叠加）

## 阶段 4：创建剪映草稿（多轨道导入原始素材）

详细脚本见 `scripts/clone_template.py`。

### 4.1 轨道结构（按层级从下到上）
```
特效轨道（粒子/光效/抖动，最上层）
文字轨道（字幕/标题/花字）
贴纸轨道（透明PNG/动图）
画中画轨道2（上层画面，可带蒙版）
画中画轨道1（下层画面）
主轨道（背景/基础画面）
音频轨道（BGM/旁白/音效，多轨叠加）
```

### 4.2 创建步骤
1. 创建工程：`JyProject(name, width=原宽, height=原高, overwrite=True)`
2. **主轨道**：按时间线导入基础画面素材（`add_media_safe(path, start, duration, track_name="VideoTrack")`）
3. **画中画轨道**：按分析结果导入叠加画面（`track_name="PIP_1"`, `"PIP_2"` 等）
4. **文字轨道**：按时间轴添加字幕（`add_text_simple`）
5. **贴纸轨道**：导入贴纸素材（`track_name="Sticker"`）
6. **音频轨道**：BGM+旁白+音效分轨导入（`track_name="BGM"`, `"Narration"`, `"SFX"`）
7. 保存工程

### 4.3 注意
- 此阶段只导入原始素材和文字，不加任何特效/转场/滤镜/关键帧/蒙版
- 画中画的缩放/位置需通过修改draft_info.json注入（jianying-editor的clip_settings不自动写入）
- 音频用mp3格式，aac可能导入失败

## 阶段 5：剪映GUI实现特效（虚拟桌面操作）

使用 `computer-use-automation` skill 操作剪映电脑版。

### 5.1 操作前准备
1. `cu.list_apps()` 找到剪映专业版
2. `cu.launch_app(exact_name)` 打开剪映
3. 打开目标工程
4. `cu.screenshot()` 观察当前状态

### 5.2 特效实现清单（按顺序操作）

| 序号 | 操作 | 方法 | 注意 |
|---|---|---|---|
| 1 | 转场 | 点击片段连接处→转场→选择类型→调整时长 | 叠化/闪白/缩放等 |
| 2 | 全片滤镜 | 特效→滤镜→选择→拖到最上层轨道 | 统一色调 |
| 3 | 关键帧 | 选中片段→基础属性→在起止位置打关键帧→调整缩放/位移/旋转 | 缩放≤1.15，0.5秒快切不加 |
| 4 | 蒙版 | 选中画中画→蒙版→选择形状→调整位置/大小/羽化 | 矩形/圆形/线性/自定义 |
| 5 | 画面特效 | 特效→画面特效→选择→拖到特效轨道→调整时长 | 粒子/光效/抖动/模糊 |
| 6 | 混合模式 | 选中画中画→混合模式→选择 | 滤色去黑底/正片叠底去白底 |
| 7 | 抠像 | 选中画中画→抠像→选择类型 | 自定义抠像/色度抠图 |
| 8 | 贴纸动画 | 选中贴纸→动画→入场/出场/循环 | 谨慎使用 |
| 9 | 文字动画 | 选中文字→动画→选择 | 打字机/弹入/淡入 |

### 5.3 操作原则
- 每次操作后 `cu.screenshot()` 验证效果
- 复杂操作（自定义蒙版路径、关键帧曲线）标注"手动微调"
- 操作失败时 `cu.hotkey("ctrl", "z")` 撤销，不硬凑
- 全部完成后 `cu.hotkey("ctrl", "s")` 保存
- 必须用剪映电脑版，不是网页版

### 5.4 已知限制
- 关键帧精确定位困难（播放头定位不精确）
- 自定义蒙版路径难以精确绘制
- 粒子特效参数调整有限
- 复杂操作建议手动完成，AI负责搭建核心结构

## 阶段 6：标记可替换素材 + 模板发布指引

### 6.1 可替换素材标记
在剪映发布模板时，"片段设置"中勾选可替换的素材：
- 主轨道的图片/视频片段
- 画中画轨道的图片/视频片段
- 不勾选：文字、贴纸、特效、滤镜、转场、音频

### 6.2 模板发布指引
生成发布步骤文档：
1. 剪映里检查效果，确认无误
2. 点击右上角"导出"
3. 导出完成后点击"发布模板"
4. 填写模板标题、描述、话题
5. 设置模板封面
6. 打开"片段设置"，勾选可替换素材
7. 首发声明（如素材为原创）
8. 付费设置（免费/付费解锁）
9. 高级设置（按需）
10. 发布

### 6.3 替换素材指引（给模板使用者）
生成使用者指引文档：
- 需要几张图片/几段视频
- 建议尺寸（如1080×1920）
- 替换顺序（按模板提示依次选择）
- 注意事项（长视频会自动裁剪，建议选择精彩部分）

## 已知限制（持续优化中）

1. **原视频剪辑手法解析**：复杂蒙版路径、自定义关键帧曲线、多层嵌套合成等高级手法暂无法100%逆向解析
2. **剪映GUI操作精度**：关键帧定位、蒙版绘制、特效参数调整等精细操作效率低，核心结构可自动化，精细调整建议手动
3. **抖音视频下载**：需用户手动下载后上传
4. **音频分离**：原视频BGM与人声混合时无法完美分离，建议保留原音轨或云端搜索纯BGM
5. **模板发布**：发布操作需用户在剪映里手动完成（涉及账号权限）
