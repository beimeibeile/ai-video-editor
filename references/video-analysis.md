# 视频分析方法（模式 B）

## 1. 基础信息探测

```bash
ffprobe -v error -show_format -show_streams input.mp4
```

提取关键字段：
- format.duration：总时长（秒）
- streams[video].width/height：分辨率
- streams[video].r_frame_rate：帧率
- streams[video].codec_name：编码格式
- streams[audio].codec_name：音频编码
- streams[audio].channels：音轨数

## 2. 镜头分割（场景检测）

### 方法一：ffmpeg scene detection
```bash
ffmpeg -i input.mp4 -filter:v "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep "showinfo"
```
- 输出每行包含 pts_time（场景切换时间点）
- 阈值 0.3：默认；快剪视频用 0.4+，慢节奏用 0.2

### 方法二：均匀抽帧+人工判断
```bash
# 每秒抽1帧
ffmpeg -i input.mp4 -vf fps=1 frame_%04d.png
```
Read 所有帧，根据画面变化判断镜头边界。

### 输出格式
```
镜头1: 0.00s - 2.17s (2.17s)
镜头2: 2.17s - 3.17s (1.00s)
镜头3: 3.17s - 3.67s (0.50s) [快切]
镜头4: 3.67s - 8.03s (4.36s)
镜头5: 8.03s - 11.03s (3.00s) [结尾页]
```

## 3. 每镜头抽帧分析

### 抽帧命令
```bash
# 每个镜头中间位置抽1帧
ffmpeg -ss {mid_time} -i input.mp4 -frames:v 1 -q:v 2 shot_{n}.png
```

### 分析维度（Read 每帧后判断）

| 维度 | 取值 | 判断依据 |
|---|---|---|
| 景别 | 特写/近景/中景/全景/远景 | 主体占画面比例 |
| 主体 | 人物/产品/文字/场景/空镜 | 画面核心元素 |
| 构图 | 居中/三分/对称/引导线/留白 | 主体位置和视觉重心 |
| 色调 | 暖黄/冷蓝/青灰/高饱和/低饱和 | 整体色彩倾向 |
| 运动方向 | 左→右/右→左/上→下/下→上/固定/旋转 | 主体或镜头运动趋势 |
| 特殊元素 | 字幕/贴纸/特效/边框/蒙版 | 画面叠加元素 |

### 输出格式
```
镜头1 (0-2.17s): 特写 | 人物面部 | 居中构图 | 暖黄色调 | 缓推 | 有字幕"对未来的真正慷慨"
镜头2 (2.17-3.17s): 中景 | 手机播放画面 | 居中 | 深色 | 固定 | 有手机框贴纸
```

## 4. 运镜分析

### 判断方法
1. 固定镜头：帧间无明显位移，主体位置稳定
2. 推近：主体逐渐变大，画面范围缩小
3. 拉远：主体逐渐变小，画面范围扩大
4. 左摇/右摇：画面水平移动
5. 上移/下移：画面垂直移动
6. 旋转：画面角度变化
7. 升格/慢动作：动作明显慢于正常速度，帧率高

### 快切标注
时长 < 0.5秒的镜头标注为"硬切快剪"，不加运镜和关键帧。

## 5. 字幕提取与识别

### 方法一：内嵌字幕流
```bash
# 检查是否有字幕流
ffprobe -v error -select_streams s -show_entries stream=index,codec_name input.mp4

# 提取字幕
ffmpeg -i input.mp4 -map 0:s:0 subtitles.srt
```

### 方法二：抽帧 OCR
```bash
# 按时间均匀抽帧（底部区域）
ffmpeg -i input.mp4 -vf "fps=2,crop=iw:ih*0.3:0:ih*0.7" subtitle_frame_%04d.png
```
Read 每帧识别字幕内容，结合时间点生成字幕时间轴。

### 输出格式
```
0.3s - 2.0s: "对未来的真正慷慨，是把一切都献给现在。" (底部居中, 白色, 约12号字)
2.5s - 3.0s: "升级版照片轮番放大" (底部, 黄色花字)
```

## 6. 音频分析

### 6.1 音轨探测
```bash
ffprobe -v error -select_streams a -show_entries stream=codec_name,channels,sample_rate input.mp4
```

### 6.2 BGM 风格判断
- 听感判断：国风（笛子/古筝/二胡）、电子（合成器/鼓机）、摇滚（电吉他/架子鼓）、抒情（钢琴/弦乐）
- BPM 估算：数10秒内鼓点数 × 6

### 6.3 旁白检测
- 通过音量变化判断：旁白段音量稳定，BGM段音量有起伏
- 有人声的片段标注旁白起止时间

### 6.4 音效点
- 转场音：镜头切换处的 whoosh/唰声
- 重鼓：强节拍点
- 定格音：画面定格时的叮/咔声
- 氛围音：持续的环境声/风声/雨声

### 输出格式
```
BGM: 电子风格, 约120BPM, 无人声
旁白: 无
音效点:
  2.17s: 转场whoosh
  3.17s: 重鼓
  3.67s: 定格叮声
  8.03s: 淡出
```

## 7. 转场与特效识别

### 转场类型
| 类型 | 特征 |
|---|---|
| 硬切 | 瞬间切换，无过渡 |
| 叠化 | 前后画面交叉淡入淡出 |
| 闪白 | 切换瞬间全白 |
| 闪黑 | 切换瞬间全黑 |
| 缩放转场 | 前画面放大/后画面缩小 |
| 滑动转场 | 画面左右/上下滑动 |

### 全片滤镜
判断整体色调：
- 青灰：冷色调，低饱和
- 暖黄：暖色调，高黄橙
- 赛博：高对比，霓虹色
- 复古：低饱和，偏色
- 清新：高明度，低对比

### 特殊特效
- 粒子/星光：画面中有浮动光点
- 光效/光晕：光源周围有光晕
- 抖动：画面轻微晃动
- 模糊/虚化：部分区域模糊
- 蒙版：画面被形状裁剪（圆形/矩形/自定义）
- 关键帧缩放：画面缓慢放大/缩小

标注每个特效的时间点和类型。

## 8. 分析汇总模板

```
=== 原视频分析报告 ===
基础信息: 720×1280, 30fps, 11.03s, H.264+AAC

镜头列表:
1. 0-2.17s (2.17s): 特写|人物|居中|暖黄|缓推|字幕"对未来的真正慷慨"|淡入
2. 2.17-3.17s (1.00s): 中景|手机画面|居中|深色|固定|手机框贴纸|硬切
3. 3.17-3.67s (0.50s): 近景|图片3|居中|深色|固定|无|硬切[快切]
4. 3.67-8.03s (4.36s): 中景|图片4|居中|深色|缓推|无|叠化
5. 8.03-11.03s (3.00s): 全屏|结尾页|居中|深色|固定|搜索框|淡出

音轨: BGM电子120BPM, 无旁白, 音效点4处

转场: 淡入+硬切×2+叠化+淡出
滤镜: 深色统一色调
特效: 手机框贴纸, 矩形蒙版, 关键帧缩放, 金色粒子

需替换素材: 图片1(0-2.17s), 图片2(2.17-3.17s), 图片3(3.17-3.67s), 图片4(3.67-8.03s)
需手动补: 蒙版微调, 关键帧, 粒子特效, 贴纸样式
```
