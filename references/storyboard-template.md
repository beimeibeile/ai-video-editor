# 分镜表模板 + 节奏公式 + Prompt 模板

## 快慢对比节奏公式

### 15秒标准版
```
慢动作钩子(2.5s) → 快切爆发(2s, 0.5s×4) → 升格高潮(5s) → 缓推收尾(2.5s) → 黑场slogan(3s) = 15s
```

### 20秒版
```
钩子(3s) → 快切(3s, 0.5s×6) → 升格(6s) → 收尾(4s) → 黑场(4s) = 20s
```

### 30秒版
```
钩子(3s) → 快切A(3s) → 升格A(5s) → 快切B(3s) → 升格B(6s) → 收尾(5s) → 黑场(5s) = 30s
```

### 节奏设计原则
- 钩子必须慢（让观众看清主体）
- 快切必须快（0.3-0.5秒，制造节奏感）
- 高潮必须升格（240fps慢动作，情绪顶点）
- 收尾必须缓（让情绪落地）
- 黑场必须有slogan（记忆点）

### 景别定义
- **特写**：面部/细节，占画面70%+
- **近景**：胸部以上，占画面50-70%
- **中景**：腰部以上，占画面30-50%
- **全景**：全身，占画面10-30%
- **远景**：人物很小，环境为主

### 运镜定义
- **固定**：镜头不动
- **缓推**：缓慢放大（缩放1.0→1.15）
- **缓拉**：缓慢缩小（缩放1.15→1.0）
- **左摇/右摇**：水平移动
- **上移/下移**：垂直移动
- **旋转**：角度变化
- **升格**：240fps慢动作（需image_to_video生成）

## 图生视频 Prompt 模板

### 普通动态片段（钩子/收尾）
```
{主体描述}, {动作描述}, {场景描述}, {光线描述}, {风格}, 镜头{运镜}, 5秒, 9:16竖屏
```
示例：
```
穿红色龙纹旗袍的女性，缓慢转身，古典园林回廊，逆光丁达尔光效，电影感，镜头缓慢推近，5秒，9:16竖屏
```

### 升格慢动作（高潮）
```
{主体描述}, {动作描述}, {场景描述}, 240fps super slow motion, {光线特效}, 衣袂飘动/发丝飞扬, {风格}, 镜头{运镜}, 5秒, 9:16竖屏
```
示例：
```
穿深蓝色旗袍的女性，回眸一笑，星空背景，240fps super slow motion, 逆光光晕+金色粒子，衣袂飘动，电影感，镜头缓慢环绕，5秒，9:16竖屏
```

### Prompt 关键词库

**光线**：逆光/侧光/顶光/丁达尔光效/光晕/柔光/硬光/霓虹光/烛光/自然光
**风格**：电影感/氛围感/高级感/复古/赛博朋克/国风/日系/欧美/港风/ins风
**运镜**：缓慢推近/缓慢拉远/左右摇移/上下移动/环绕旋转/固定/跟随
**特效**：金色粒子/星光/光晕/烟雾/花瓣飘落/雪花/水滴/光轨
**情绪**：优雅/神秘/性感/清冷/热烈/忧郁/欢快/庄重/俏皮
