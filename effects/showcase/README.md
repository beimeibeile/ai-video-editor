# 特效库对标展示系统

## 目录结构

```
effects/showcase/
├── index.json                    # 展示索引（所有特效的展示元数据）
├── mask_flash_transition/        # 蒙版展开快闪
│   ├── README.md                 # 特效说明
│   ├── tutorial_frames/          # 原始教程关键帧
│   ├── demo_frames/              # 封装效果关键帧
│   └── test_project.txt          # 测试工程名
├── subtitle_bar/                 # 半透明字幕条
├── intro_builder/                # 片头生成器
└── character_intro/              # 人物介绍卡片
```

## 展示字段说明

每个特效展示包含：
- **原始教程**：来源、关键帧截图、核心手法
- **封装效果**：测试工程名、演示关键帧、参数配置
- **API接口**：函数名、参数说明、使用示例
- **已知限制**：API不支持的功能、降级方案
- **对标状态**：效果还原度评估

## 效果还原度评级

- ⭐⭐⭐⭐⭐ 完美还原
- ⭐⭐⭐⭐ 高度还原（细微差异）
- ⭐⭐⭐ 基本还原（部分功能降级）
- ⭐⭐ 部分实现（核心效果可用）
- ⭐ 原型阶段
