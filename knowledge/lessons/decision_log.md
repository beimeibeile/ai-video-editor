# 封板决策日志

> 所有关键架构决策、技术选型、用户确认的结论记录于此。新决策追加在末尾。

## #1-24 基础架构决策（2026-09-24~26）
1. 转场/特效API："工程预留+手动补"，叠化可自动
2. 贴纸纳入标准流程，全片≤3个
3. 音效层纳入标准流程，全片≤6个
4. 关键帧运镜纳入标准流程，≥2秒静态图缩放≤1.15
5. 导出失败提示手动导出，不做ffmpeg兜底
6. 人脸一致性在素材探查阶段询问
7. 调色接受"剪映工程里手动套滤镜"
8. 多比例/多时长参数化支持
9. 封面生成询问确定
10. macOS用户手动导出
11. 剪映优先原则：能剪映搞定的优先用剪映
12. 视频预处理强制ffmpeg转码
13. media_normalizer bug必须修复
14. 双模式：模式A制作视频 + 模式B仿制模板
15. 模式B最终产物：可发布的剪映模板草稿
16. 模式B素材铁律：只放原始素材，特效全部在剪映GUI实现
17. 模式B多轨道：禁止单轨
18. 模式B特效通过GUI实现
19. 模式B可替换标记在发布模板时设置
20. 模式B分析维度必须包含多轨道/蒙版/关键帧/混合模式
21. 模式B强制使用5.9版本
22. 模式B GUI用PowerShell Windows API
23. 模式B返回主页用Ctrl+W
24. 模式B特效必须拖拽到时间线

## #25-28 极速模式（2026-09-27）
25. 极速模式=模式A免确认版，触发词"快剪视频"
26. 文字说明权重高于素材理解
27. 默认参数15s/9:16/氛围感
28. 边界保护：素材全废或文字与素材冲突时才询问

## #29-35 动态艺术字幕与v4（2026-09-27）
29. 动态艺术组合式字幕：三轨道结构（ArtTitle+ArtSubtitle+ArtNarration）
30. 4种风格预设：epic/warm/fun/minimal
31. Ken Burns关键帧：交替放大/缩小，EASE_IN_OUT
32. 转场位置：给前一片段添加
33. 旁白时间：固定2.5s+间隔0.3s
34. 5.9含BGM工程显示00:00（BGM路径问题）
35. add_styled_text()未实现（花字API缺失）

## #36-40 自学习框架与制作素材模块（2026-09-28）
36. 采用模块化架构：core/ + capabilities/ + knowledge/ + assets/ + utils/
37. 能力模块可插拔，新能力放入capabilities/自动发现
38. 自学习机制：经验自动沉淀到knowledge/lessons/
39. 素材复用：生成的可复用素材归档到assets/reusable/
40. 制作素材模块(cap_material_creator)作为第一个能力模块，支持用户触发和自主触发
41. 混合模式用Python预合成替代剪映blend_mode API（jianying-editor不支持）
42. 多个特效用不同track_name避免轨道重叠
