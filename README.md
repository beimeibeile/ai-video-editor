## 3步上手

### 第1步：安装（只需一次）

```bash
git clone https://github.com/beimeibeile/ai-video-editor.git
cd ai-video-editor
pip install requests pillow numpy
```

### 第2步：配置（填入你的API Key和软件路径）

复制 `.env.example` 为 `.env`，填入：
- ComfyUI 地址（本地运行即可）
- 剪映安装路径（5.9版本，免费）
- 可选：Blender路径（用于3D特效）

### 第3步：开始创作

用自然语言描述你想要的视频，例如：

```
"帮我做一个30秒的国庆旅行vlog，风格轻快活泼，要有字幕和转场特效"
```

AI 会自动：
1. 📝 生成剧本（三幕结构+情感曲线+钩子设计）
2. 🎬 智能分镜（运镜+特效+节奏自动决策）
3. 🎨 生成素材（ComfyUI文生图/图生视频）
4. ✂️ 剪映合成（多轨道+转场+字幕+特效）
5. ✅ 质量检查（帧对齐+时长校验+HTML报告）

完成后直接在剪映中打开工程，微调后导出即可发布！

## 核心亮点

### 🧠 智能剧本引擎（v2质量版）
- **人性认知**：自动设计情感曲线、角色弧光、冲突张力
- **钩子优化**：前3秒抓人，8种钩子类型自动匹配
- **节奏控制**：快慢交替，张弛有度
- **质量评分**：6维度自动评估（钩子/情感/冲突/角色/节奏/结构）

### ⚡ 三模式剪辑
| 模式 | 适合场景 | 特点 |
|------|---------|------|
| **制作视频** | 有素材，想精细剪辑 | 上传素材→AI分镜→确认→合成 |
| **快剪视频** | 快速出片，不纠结 | 一句话直接出片，免确认 |
| **仿制模板** | 参考别人的视频风格 | 分析参考视频→生成同款模板 |

### 🎨 25+ 自研特效库（持续扩展）
- **转场**：蒙版快闪、百叶窗分屏、Blender 3D转场
- **文字**：羽化擦开、背景滑入、字幕条高光、文字排版艺术
- **视觉**：发光轮廓、混合模式、照片墙、多层堆叠
- **3D**：Blender片头（4风格）、粒子背景（5种）、光线扫描

### 🔗 全链路自动化
```
你的一句话 → 剧本生成 → 智能分镜 → 素材生成(ComfyUI) → 剪映合成 → 质量门 → 成品
```

### 📊 双重质量门
- **分镜质量门**：18项检查，HTML可视化报告
- **剪辑质量门**：帧对齐、时长校验、片段完整性
- 问题一目了然，返工率大幅降低

### 🔄 自我进化

## 常见问题

**Q：需要付费吗？**
A：完全免费开源。依赖的剪映5.9、ComfyUI、Blender也都是免费软件。

**Q：我的电脑配置要求高吗？**
A：基础功能普通电脑即可。ComfyUI生成视频需要显卡（N卡最佳），没有显卡也可以用云端算力。

**Q：生成的视频版权归谁？**
A：你生成的内容归你所有。AI只是工具，创意是你的。

**Q：可以商用吗？**
A：MIT协议，可自由商用。但请注意使用的素材和音乐的版权。

**Q：和剪映官方的AI功能有什么区别？**
A：剪映官方AI是封闭的，这个项目是开源可定制的。你可以自由扩展特效、调整流程、接入自己的模型。

- **语言**：Python 3.10+
